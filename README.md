# SunMall – Potato Chips Landing Page 🍟

A modern and visually attractive potato chips landing page created using HTML5 and CSS3, with a major focus on CSS Flexbox for layout building and element alignment.

### ✨ Design Sections
- Navigation bar with logo, menu, search bar and cart icon.
- Hero section with product image and attractive typography.
- Add to Cart button UI and quantity selector design.
- Product highlights and ingredient information.
- Top flavours section with product cards.
- Attractive colours, icons and typography.

### 🛠️ Technologies Used
- HTML5
- CSS3
- CSS Flexbox

### 🎯 Learning Outcomes
- Understanding practical CSS Flexbox layouts.
- Aligning and positioning elements.
- Creating product cards and website sections.
- Managing spacing, margins and padding.
- Improving HTML structure and CSS styling.

**Note:** This is a static frontend design project created for HTML and CSS practice. Buttons and cart elements are currently UI-only and do not have functional interactions.
